
### Label for failed changes

```bash
gh label create hotfix --repo OWNER/notes-app --color d93f0b --description "Fixes a bad change on main" --force
```

### Label for incidents

```bash
gh label create incident --repo OWNER/notes-app --color b60205 --description "A defect found on main. Link the change that caused it" --force
```

